# Лабораторная 1 — вариант 4

C++20. Динамический массив, гномья сортировка, бинарный поиск и удаление всех вхождений числа. Все операции из задания сохранены; 37 тестов Google Test.

## Файлы

- `main.cpp` — меню и проверка ввода.
- `array_ops.h` — объявления функций.
- `array_ops.cpp` — все операции массива.
- `tests.cpp` — тесты.
- `CMakeLists.txt` — сборка программы и тестов.

## Запуск на macOS

Открой `run.command` или выполни из этой папки:

```sh
./run.command
```

Нужен компилятор C++ из Xcode Command Line Tools. Исходники пересобираются при запуске. После сборки с CMake тесты можно запустить командой `./build/lab01_tests`.

## Сборка с CMake

Нужны CMake 3.16+ и компилятор C++20. При первой сборке CMake скачает Google Test 1.14.0, поэтому требуется интернет.

```sh
cmake -S . -B build
cmake --build build
./build/lab01_main
ctest --test-dir build --output-on-failure
```

## Контрольный пример

Создай массив длины 6: `2 5 2 8 2 1`. Пункт `7`, удаляемое число `2`: после сортировки `{1, 2, 2, 2, 5, 8}`, после удаления `{1, 5, 8}`, размер 3, удалено 3. Пункт `8` сортирует перед поиском; индекс относится к показанному отсортированному массиву. Индексы начинаются с 0.

Функция `array_remove_all` сама не сортирует: на исходном примере из PDF оставляет `{5, 8, 1}`. В ней уменьшается используемая длина, а выделенный блок сохраняется до последующего перевыделения или удаления.

Отчёт в PDF не требуется.
