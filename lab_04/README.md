# Лабораторная № 4. Вариант 6 — электроника

| Класс | Поля | Метрика в омах | Особый метод |
| --- | --- | --- | --- |
| `Resistor` | `R ≥ 0` Ом, `tol` от 0 до 100 % | `R` | `tolerance()` |
| `Capacitor` | `C > 0` Ф, `polar` (0 или 1) | `1 / (2πfC)` | `isElectrolytic()` |
| `Inductor` | `L ≥ 0` Гн, `air_core` (0 или 1) | `2πfL` | `isAirCore()` |

## Контракт

- [x] `Component` абстрактный. `metric`, `print`, `read` и `clone` чисто виртуальные, потому что формулы, поля и тип копии определяет конкретный прибор. Наследники помечают реализации `override`.
- [x] Виртуальный деструктор с реализацией по умолчанию позволяет удалять прибор через `Component*`.
- [x] Методы чтения полей, расчёта, печати и создания копии помечены `const`. Метод `read` меняет поля.
- [x] Свободные `<<` и `>>` вызывают виртуальные `print` и `read`. Потоковый ввод принимает и формат вывода.
- [x] `operator double` возвращает метрику. `operator==` сравнивает метрики с точностью `1e-6`.
- [x] У каждого прибора есть особый метод из таблицы. В меню он вызывается после проверки результата `dynamic_cast`.
- [x] `Collection` владеет динамическим массивом указателей и приборами. При добавлении она сохраняет копию прибора, при удалении освобождает её.
- [x] Коллекция реализует правило пяти. `clone()` сохраняет тип при глубоком копировании. Приборы передаются по ссылкам или указателям, поэтому срезки нет.

## Ввод и вывод

Сначала введите положительную частоту в герцах и выберите тип прибора.
Индексы начинаются с нуля.

| Прибор | Ввод | Вывод |
| --- | --- | --- |
| Резистор | `100 5` | `Resistor: R=100 tol=5%` |
| Конденсатор | `1e-6 1` | `Capacitor: C=1e-06 F polar=1` |
| Катушка | `0.01 1` | `Inductor: L=0.01 H air_core=1` |

Меню выводит метрику каждого прибора и сумму метрик коллекции.

Из папки лабораторной запустите `./run.command`.

## Сборка и тесты

Нужны CMake 3.20+ и компилятор C++20. Цель `lab04` собирает меню из
`main.cpp`, `component.cpp` и `collection.cpp`. Цель `lab_04_tests`
собирает 10 тестов из `test_electronics.cpp`. При первой сборке CMake
загружает Google Test.

```sh
cmake -S . -B build
cmake --build build
ctest --test-dir build --output-on-failure
./build/lab04
```

## Проверка памяти

```sh
cmake -S . -B build-asan -DCMAKE_BUILD_TYPE=Debug -DCMAKE_CXX_FLAGS="-fsanitize=address,undefined"
cmake --build build-asan
ctest --test-dir build-asan --output-on-failure
```

На macOS утечки можно проверить отдельно командой `leaks --atExit -- ./build/lab_04_tests`.
