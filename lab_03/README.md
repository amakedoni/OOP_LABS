# Лабораторная № 3. Вариант 12 — множество книг

Книга хранит название в `char*` и год. Множество хранит книги в динамическом
массиве, отсортированном по названию и году. Повтором считается совпадение
обоих полей.

Добавление, удаление и проверка принадлежности используют двоичный поиск.
Объединение `|`, пересечение `&` и разность `-` используют слияние.
Копирование и перемещение реализованы для книги и множества.
Копирующее присваивание использует copy-and-swap. Перемещение помечено
`noexcept` и оставляет источник пустым.
Индекс позволяет только читать книгу и проверяет границы.

Из папки лабораторной запустите `./run.command`.

## Сборка и тесты

Нужны CMake 3.20+ и компилятор C++20. При первой сборке CMake загружает
Google Test.

```sh
cmake -S . -B build
cmake --build build
ctest --test-dir build --output-on-failure
./build/lab03
```

В меню можно создать множество, напечатать его, добавить или удалить
книгу, проверить принадлежность, выполнить операцию с другим множеством
или вывести книгу по индексу. Название вводится отдельной строкой
до 255 байт, год — целым числом. Индексы начинаются с нуля.

## Проверка памяти

```sh
cmake -S . -B build-asan -DCMAKE_BUILD_TYPE=Debug -DCMAKE_CXX_FLAGS="-fsanitize=address,undefined"
cmake --build build-asan
ctest --test-dir build-asan --output-on-failure
```

На macOS утечки можно проверить отдельно командой `leaks --atExit -- ./build/lab_03_tests`.
