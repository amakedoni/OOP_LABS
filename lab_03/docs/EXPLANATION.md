# Объяснение лабораторной 3

Вариант 12 — множество книг. Обязательные свойства: динамический массив,
ручное управление памятью, правило пяти, сортировка, двоичный поиск,
слияние и индекс только для чтения с проверкой границ.

## Книга Book

`title_` — адрес строки, `year_` — год. Конструктор выделяет `strlen + 1`
байт и копирует название через `strcpy`. Дополнительный байт нужен для
`'\0'`. Деструктор освобождает строку через `delete[]`.

Копирующий конструктор создаёт свою строку. Копирующее присваивание
создаёт временную копию и меняется с ней данными через `swap`.
Перемещение передаёт адрес и год, затем обнуляет источник. Перемещающее
присваивание сначала освобождает старую строку. Проверка `this != &other`
защищает от присваивания самому себе.

Равенство учитывает название и год. Порядок задаёт `strcmp`, а при равных
названиях — год. `title()` позволяет прочитать название, включая пустое
название у перемещённого объекта. Вывод: `("Alpha", 2001)`.

## Множество BookSet

`data_` — массив книг, `size_` — число используемых ячеек, `capacity_` —
число выделенных ячеек. Всегда `size_ <= capacity_`, элементы отсортированы
и не повторяются. Пустое множество имеет нулевой размер.

Копия получает собственный массив и собственные строки книг.
Копирующий конструктор собирает копию во временном множестве: если
копирование прервётся, временный объект освободит уже выделенную память.
Копирующее присваивание использует copy-and-swap, как требует задание.
Если создание копии не удалось, прежнее множество остаётся прежним.

Перемещение передаёт три поля и обнуляет источник. Деструктор удаляет
массив, а деструкторы его книг удаляют строки.

`reserve` увеличивает ёмкость: выделяет новый массив, переносит книги,
удаляет старый массив. При добавлении ёмкость растёт как 1, 2, 4, 8 и далее.

## Поиск добавление и удаление

`find_position` двоичным поиском находит первую книгу, которая не меньше
заданной. Если такой нет, возвращается `size_`. Полуинтервал поиска —
`[left, right)`. На каждом шаге остаётся примерно половина диапазона.

`contains` проверяет, что найденная позиция внутри массива и книга равна
заданной. `operator()` вызывает `contains`.

`add` отбрасывает дубликат, копирует новую книгу, расширяет массив при
необходимости и сдвигает книги вправо с конца. Потом вставляет книгу и
увеличивает размер. Копия нужна, чтобы подготовить строку до сдвигов.

`remove` находит книгу, сдвигает следующие элементы влево, уменьшает размер
и очищает освободившуюся ячейку. Ёмкость не уменьшается. `+=` и `-=`
вызывают `add` и `remove`, затем возвращают `*this` по ссылке.

## Операции множеств

Два индекса проходят по отсортированным массивам только вперёд.
Объединение копирует меньшую книгу, а при равенстве — одну из двух.
Пересечение пропускает меньшую и сохраняет только совпадения.
Разность `A - B` сохраняет книги из A, которых нет в B.
Операторы создают новый результат, исходные множества не меняют.

`==` сравнивает размеры и элементы на одинаковых местах, потому что
порядок хранения всегда одинаков. `!=` отрицает результат `==`.

`operator[]` возвращает `const Book&`: книгу можно читать, но нельзя
заменить и нарушить сортировку. При `index >= size_` бросается строка
типа `const char*`. Меню проверяет индекс перед обращением и при ошибке
выводит сообщение; сам оператор также проверяется тестом. Вывод множества: `{ ("Alpha", 2001) }`,
пустого — `{}`.

## Меню и проверки

В `main.cpp` находятся ввод книги, ввод множества и печать результата.
Меню позволяет вручную создавать множества и вызывать операции классов.
Для операций 6–9 второе множество вводится заново; первое сохраняется.
`0` завершает работу. Название читается целой строкой до 255 байт,
`std::ws` пропускает перевод строки перед ним. Ввод рассчитан на
корректные целые числа; при ошибке чтения программа завершается.
Ввод множества сначала заполняет временный объект, затем заменяет
целевой через `swap`. При прерванном вводе целевой объект ещё не изменён.

21 тест Google Test проверяет книгу, множество, независимость копий,
перемещения, самоприсваивание, операции, вывод, границы и 1000 книг.
Для стресс-теста используется одно название и 1000 разных годов:
это 1000 разных элементов, упорядоченных по году.

Поиск — O(log n) сравнений. Добавление и удаление — O(n) перемещений.
Слияние — O(n + m) сравнений. Доступ по индексу — O(1).
Сравнение и копирование строк также зависят от длины названий.
