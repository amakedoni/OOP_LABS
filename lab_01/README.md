# Лабораторная работа 1 — вариант 4

Семейство A: динамический массив целых чисел. C++20, CMake 3.16+ и Google Test.
Решение написано заново по `lab_01_basics_2026-08-16.pdf`.

## Быстрый запуск на macOS

Откройте `run.command` двойным щелчком или выполните из этой папки:

```sh
./run.command
```

Скрипт собирает программу компилятором `c++` и запускает меню. Нужны Xcode
Command Line Tools; CMake и интернет для этого способа не требуются.
Если инструменты компилятора ещё не установлены: `xcode-select --install`.

## Сборка и тесты через CMake

Нужны CMake 3.16+, компилятор C++20 и интернет при первой настройке:

```sh
cmake -S . -B build
cmake --build build
./build/lab01
```

Запуск 35 тестов Google Test и 8 проверок меню:

```sh
cd build
ctest --output-on-failure
```

Google Test 1.17.0 скачивается автоматически; SHA-256 архива закреплён в
`CMakeLists.txt`. Подключение основано на [официальной инструкции Google Test](https://google.github.io/googletest/quickstart-cmake.html).
При наличии локальных исходников можно передать
`-DFETCHCONTENT_SOURCE_DIR_GOOGLETEST=/путь/к/googletest`.
Сборка только программы без скачивания тестовой библиотеки:

```sh
cmake -S . -B build-app -DBUILD_TESTING=OFF
cmake --build build-app
```

Проверка памяти и неопределённого поведения для Clang/GCC:

```sh
cmake -S . -B build-sanitized -DENABLE_SANITIZERS=ON
cmake --build build-sanitized
cd build-sanitized
ctest --output-on-failure
```

## Меню

| Пункт | Действие |
| --- | --- |
| 1 | Создать массив, ввести размер и элементы |
| 2, 6 | Напечатать массив и длину; оба пункта сохранены из методички |
| 3 | Вставить число в позицию от 0 до текущей длины включительно |
| 4 | Удалить элемент по индексу от 0 до длины минус 1 |
| 5 | Изменить размер; новые элементы заполнить нулями |
| 7 | Гномья сортировка, затем удаление всех вхождений указанного числа |
| 8 | Сортировка и бинарный поиск с выводом индекса и значения |
| 0 | Освободить память и завершить программу |

Числа можно вводить через пробелы или по одному на строке. Дроби, текст,
числа вне диапазона `int` и отрицательные размеры отклоняются. После ошибки
ввода остаток строки пропускается. EOF завершает программу с освобождением
как текущего массива, так и недовведённого нового массива.

## Контрольный пример

В пункте 1 введите размер `6`, затем числа `2 5 2 8 2 1`.
Выберите пункт 7 и число `2`:

```text
После сортировки:
Массив: {1, 2, 2, 2, 5, 8}
Размер: 6
Удалено элементов: 3
Массив: {1, 5, 8}
Размер: 3
```

В пункте 8 поиск `5` вернёт индекс `1` и значение `5`.
Индекс относится к показанному отсортированному массиву.

Отдельная функция `array_remove_all` не сортирует: на исходном массиве
`{2, 5, 2, 8, 2, 1}` она оставит `{5, 8, 1}`, обновит длину до `3` и вернёт
`3`, как в примере PDF. Порядок оставшихся элементов сохраняется.

## Файлы и устройство решения

- `array_ops.h` — объявления функций и правила их использования.
- `array_ops.cpp` — реализация операций массива и алгоритмов.
- `main.cpp` — меню, ввод и обработка ошибок выделения памяти.
- `test_variant.cpp` — 35 Google Test; `tests/check_menu.cmake` — проверки меню.
- `CMakeLists.txt` — библиотека `array_ops`, программа `lab01`, тесты.

Массив хранится в `int*`; длина передаётся отдельно. Пустой массив при
создании представлен `nullptr` и длиной `0`. Вставка, удаление по индексу
и изменение размера выделяют новый блок, копируют элементы и освобождают
старый; полученный указатель необходимо присвоить обратно, например
`arr = array_resize(arr, size, new_size)`. При неудачном выделении прежний
массив сохраняется. `array_delete` обнуляет указатель.

`array_remove_all` сжимает элементы в том же блоке двумя индексами, обновляет
длину по ссылке и возвращает число удалённых. Выделенная память остаётся
до последующего перевыделения или освобождения, даже если новая длина равна 0.

Поиск имеет сигнатуру с `out_index` из методички и перегрузку с дополнительным
`int& out_value`. Он возвращает первое вхождение; при неудаче выходные параметры
сохраняют прежние значения. Поиск требует отсортированного массива.

Все алгоритмы отделены от ввода/вывода; отдельно реализована обязательная
`array_print`. Собственных классов, `std::string`, контейнеров и умных
указателей нет. Google Test как внешняя библиотека использует свои классы.

Гномья сортировка сравнивает соседей и после обмена делает шаг назад:
O(n²) в худшем случае, O(n) для уже отсортированного массива, O(1) памяти.
Бинарный поиск: O(log n). Удаление всех вхождений: O(n), O(1) памяти.
Вставка, удаление по индексу и перевыделение: O(n) времени и O(n) памяти.
