# Лабораторная 1, вариант 4

Основание: PDF задания, страницы 1–5 и 7. Пользователь подтвердил новое решение.

- Отдельный проект `lab_01`: C++20, CMake 3.16+, библиотека и консольное меню.
- Массив `int*`, ручное управление через `new[]` / `delete[]`; без собственных
  классов, `std::string`, контейнеров и умных указателей.
- Создание, освобождение, изменение размера, вставка, удаление по индексу,
  гномья сортировка, бинарный поиск, удаление всех вхождений числа.
- Сигнатуры методички; дополнительная перегрузка поиска возвращает значение
  по ссылке. При неудаче выходные параметры не меняются.
- `array_create(0)` возвращает `nullptr`; после освобождения указатель обнуляется.
  После удаления всех вхождений блок может сохраняться при логической длине 0.
  Новые элементы при увеличении размера нулевые. Индексы начинаются с 0.
  Неверный индекс не изменяет массив. При ошибке выделения старый массив цел.
- Алгоритмы не вводят и не выводят данные; `array_print` — обязательная
  функция печати из интерфейса методички.
- Меню: базовые операции A; пункт 7 сортирует и удаляет все вхождения.
  Перед поиском массив сортируется, результат показывается пользователю.
- Сама `array_remove_all` сохраняет порядок: пример PDF даёт `{5, 8, 1}`.
- Проверка ввода, EOF, нехватка памяти; минимум 10 Google Test.
- Приёмка: CTest, сценарии меню, AddressSanitizer и UndefinedBehaviorSanitizer.
